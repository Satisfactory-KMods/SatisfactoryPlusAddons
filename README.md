Satisfactory Plus Addons supplies optional content modules for Satisfactory Plus.

---

## 🧩 Modules

- Module packs extend Satisfactory Plus through KDataForge.
- No module packs are included yet.

{{GALLERY}}

## 🔧 Technical details

- Packs require the same files on multiplayer peers.

## Requirements

| Mod | Purpose |
| --- | --- |
| [Satisfactory Mod Loader](https://ficsit.app/mod/SML) | Mod loading |
| [KDataForge](https://ficsit.app/mod/KDataForge) | Pack loading |
| [Satisfactory Plus](https://ficsit.app/mod/SatisfactoryPlus) | Module content |
